Seguretat i fiabilitat — què cal saber abans de fer clic

Pot al·lucinar la IA? Sí, és un risc real de qualsevol traductor amb LLM — no ho amaguem. Per això cada traducció passa per un Traductor i un Revisor independents (dues crides separades), més tres verificacions mecàniques (nombres/unitats, terminologia protegida, URLs).

Es publica sol, sense revisió humana? Per defecte, mai — tota traducció queda com a esborrany pendent de revisió. Existeix un mode autònom opcional (AUTO_PUBLISH_MODE a .env), desactivat de fàbrica, que l'operador ha d'activar explícitament — quan ho està, ho veuràs sempre com un avís vermell a dalt de tot d'aquesta pàgina, mai en silenci.

Pot fer un SQL injection o similar? Pràcticament no, per arquitectura: aquest motor no té cap connexió a base de dades, només parla amb WordPress via la seva API REST autenticada — el mateix camí que faria servir un editor humà.

I si la IA generés HTML perillós (<script>)? Es filtra amb una llista blanca d'etiquetes abans que arribi enlloc — app/qa/html_sanitizer.py.

Aquest panell mateix: només escolta a 127.0.0.1 (mai accessible des de fora del teu ordinador) i cada acció requereix un token secret generat a cada arrencada, perquè cap altra pàgina web oberta en una altra pestanya pugui disparar accions aquí sense que tu ho sàpigues.

Detall complet i honest (inclosos els límits reals, no només el que funciona bé) al README del projecte.
